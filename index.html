Common questions about this recreation.

Does this edit videos with AI?

No. This is a static front-end recreation. AI processing needs a backend and external APIs.

Does my file get uploaded?

No. The file picker only displays the filename. Your file stays on your device.

Can I publish it with GitHub Pages?

Yes. Enable Pages in the repository Settings and deploy from the main branch root.

Can I customize the site?

Yes. Edit index.html to change the text, styles, templates, and categories.
